EXPLANATION: WHY MAXIMUM DEW-POINT CHANGE IS 8.91 C AT +1.5 C FOR SHIMLA
================================================================================================================================================================
1. Peak Inconsistency Hour Identification:
   * Hour Index in Year:   Hour 5274 of 8760 (Date: Month 8, Day 8, Hour 18:00)
   * Raw EPW Dry-Bulb:     25.50 C
   * Raw EPW Dew-Point:    16.50 C
   * Raw EPW Rel-Humidity: 91.0 %
   * Psychrometric Tdp:    23.92 C (calculated from 25.50 C and 91.0 % via Magnus formula)
   * Raw Sensor Discrepancy: 7.42 C (the raw EPW dew-point is 7.42 C lower than physical saturation physics)

2. Mechanism of the 8.91 C Artifact in src/sim/morph_epw.py:
   * The morphing code executed: t_dp_new = magnus_dew_point(t_db + 1.5, rh)
   * For this hour: t_db_new = 25.50 + 1.50 = 27.00 C
   * Calculated t_dp_new = magnus_dew_point(27.00, 91.0) = 25.41 C
   * Reported Delta vs Raw: 25.41 - 16.50 = 8.91 C (exactly 8.91 C)
   * Decomposition of 8.91 C:
     8.91 C = 7.42 C (initial thermodynamic inconsistency in raw EPW) + 1.49 C (true psychrometric warming shift)
   * Conclusion: The current morph did NOT apply a delta to the baseline dew-point; instead, it recomputed dew-point
     from scratch using the Magnus formula. Where raw EPW sensors had internal psychrometric inconsistencies,
     this caused a large artificial 'jump' (up to 8.91 C in Shimla, 6.77 C in Mumbai, 6.10 C in Delhi) that reflects
     sensor calibration discrepancy rather than true climate warming.
